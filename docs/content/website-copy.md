# Aspio Ethiopia — Website Copy Deck

This document contains the current public-facing English copy for the Aspio Ethiopia website. Edit the wording directly in this file and send it back for implementation.

Scope: the public Ethiopia website only. The separate Sweden website, the disabled Amharic source, admin interface instructions, developer messages and backend errors are intentionally excluded. Dynamic salon and gallery content added through the admin is identified separately.

**Editor's notes on this revision:** Rewrote for tone and removed dashes throughout, this account never uses them. Several sections (hero, gallery, closing culture) had drifted into a more lyrical, lifestyle-brand voice than Aspio uses anywhere else, tightened those to match the direct, benefit-first style used on the Sweden site and in ads. Kept the Ethiopian calendar section largely as is, that's genuine localization, not just translation, and it's a real strength. Updated the contact email to semere.e@aspio.se. One open question worth raising separately: Amharic is noted as disabled on a consumer-facing marketplace, worth confirming that's intentional given the audience booking appointments day to day may not all be as comfortable in English as the business owners on the B2B side.
